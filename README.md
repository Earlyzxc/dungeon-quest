# Dungeon Quest

A text-based RPG where an adventurer travels around the world and defeats monsters. Built in Python as a learning project, one phase at a time.

## Phases
[x] Phase 1: Core (player name, HP, gold, main menu)
[ ] Phase 2: Battles (random monsters, attacks, critical hits, flee)
[ ] Phase 3: Loot and inventory
[ ] Phase 4: Leveling (EXP and stats)
[ ] Phase 5: Classes and OOP (Player, Monster, Item)
[ ] Phase 6: Save and load
[ ] Phase 7: Data and charts
[ ] Phase 8: Leaderboard website
[ ] Phase 9: Discord or Telegram bot
